# ML Buyer Segmentation for Real Estate

Objective
To segment potential real estate buyers using machine learning techniques and visualize insights through an interactive dashboard.

Dataset
The dataset contains information about buyers including demographic and purchasing characteristics.

 Technologies Used
- Python
- Pandas
- Streamlit

Machine Learning Technique
Customer Segmentation using Clustering.

Features
- Data Cleaning
- Exploratory Data Analysis
- Buyer Segmentation
- Interactive Dashboard
- Visualization of Insights

Files Included
- app.py
- Dataset
- Dashboard Screenshots
- Project Report
- Jupyter Notebook

## Conclusion
The project helps identify different buyer segments and supports data-driven real estate marketing decisions.
